# 205chating 0.1.5v — Soft Launch

Версия для мягкого запуска. Сохранены личные сообщения, 205chat, реакции, голосовые, видео-треугольники, подарки/NFT, клубнички, поддержка и админ-панель.

## Что подготовлено к мягкому запуску
- единый синий акцент, улучшенные hover/focus/active состояния и анимации;
- экран запуска, индикатор потери/восстановления соединения, понятные пустые состояния;
- защита от повторной отправки форм и зависших запросов;
- ограничение частоты входов и сообщений от спама;
- лимит сообщений 4000 символов и загрузок до 45 МБ;
- более аккуратные ошибки загрузки и HTTP-ошибки;
- атомарная запись `data/db.json` и резервная копия `db.json.bak`;
- `/health` возвращает состояние и версию приложения;
- администратор не блокируется экраном технического перерыва и может закончить обслуживание;
- исправлены остаточные CSS-артефакты старых обновлений и обновлён cache-busting до 0.1.5v.

## Запуск
```bash
npm install
npm start
```

Railway использует `process.env.PORT`, сервер слушает `0.0.0.0`. Для публичного запуска обязательно задайте переменную `JWT_SECRET` длинной случайной строкой.

## Важно перед реальными платежами
Сейчас данные хранятся локально в `data/db.json`, а медиа — в `data/uploads`. На Railway это нельзя считать надёжным постоянным хранилищем. Для полноценного публичного запуска нужно перенести пользователей, сообщения, балансы, покупки, подарки и поддержку в PostgreSQL, а медиа — в постоянное объектное хранилище.

Пароли хранятся только как bcrypt-хеши и не показываются администратору.

## Мини-чеклист мягкого запуска
1. Задать `JWT_SECRET` в Railway Variables.
2. Создать тестовые аккаунты и проверить вход/регистрацию.
3. Проверить личный чат, 205chat, фото, голосовое и видео-треугольник на телефоне и ПК.
4. Проверить поддержку и заявку на 🍓 без реального крупного платежа.
5. Проверить создание/удаление подарка и NFT администратором.
6. Проверить технический перерыв на обычном аккаунте.
7. Сделать резервную копию `data/db.json` перед каждым заметным обновлением.
