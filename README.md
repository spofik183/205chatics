# 205chating v9

Обновление v9:
- пополнение 🍓 перенесено в Настройки → Баланс;
- чат поддержки получил локального мини-помощника по частым вопросам, после ответа администратора бот перестаёт вмешиваться;
- однотонная SVG-кнопка подарков открывает отдельный экран рынка;
- администратор создаёт подарки и NFT: изображение, название, цена и количество на рынке;
- NFT получают порядковый номер при отправке;
- подарки находятся в отдельной вкладке профиля, один подарок можно закрепить;
- сохранены функции v7/v8: личные сообщения, реакции, медиа, квадрат-видео, настройки канала и админ-панель.

## Запуск
```bash
npm install
npm start
```

Railway использует `process.env.PORT` и сервер слушает `0.0.0.0`. Установите переменную `JWT_SECRET`.

## Важно о хранении
`data/db.json` и `data/uploads` — локальное хранение. На Railway файловая система деплоя может быть непостоянной. Перед использованием реальных платежей нужно перенести пользователей, балансы, покупки, подарки и каталог в постоянную БД, а изображения — в постоянное объектное хранилище.

Пароли хранятся только как bcrypt-хеши и не показываются администратору.
